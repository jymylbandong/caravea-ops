## The main one

While reviewing the frontend in the browser, I noticed the page was
rendering in a serif font instead of the intended sans-serif. I traced it
to the CSS that `shadcn init` generated: `--font-sans` was defined as
`var(--font-sans)`, a variable referring to itself, so it resolved to
nothing and the browser fell back to its default serif font. I pointed it
at Next.js's `--font-geist-sans` variable instead.

Most other mistakes were caught by the test suite or by Claude while
running it, which is why I kept tests running at every step.
